# Heatmap роллер-треков

## Источники данных
- **Треки**: анонимизированные публичные GPS-треки из роллерских сообществ Strava и Sports Tracker
- **Планируемые дорожные работы**: данные с https://data.mos.ru/opendata/62101/
- **Информация о состоянии асфальта**: используется внешний сервис для обработки формы опроса.


## Как запустить
- собрать GPX-файлы в папку TRACKS_DIR ;
- запустить main.py для создания карты;
- использовать получившийся index.html .

## Возможные улучшения
- Связать с трекерами
- Добавить велодорожки
- Автоматическое определение "плохого асфальта" по резким замедлениям.
